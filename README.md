# Вдохновение Астрала

Стратегия по мотивам вселенной Эадора — правила, игровые кабинеты, Владыки и управление партиями VA-34.

## Основные страницы

- `index.html` — главная страница, правила и энциклопедия.
- `auth.html` — вход и регистрация.
- `cabinet.html` — личный кабинет игрока.
- `games.html` — страницы игр: Владыки, Осколки, Ходы ИС и заявки.
- `lord.html?id=...` — универсальная страница Владыки.
- `master.html` — кабинет игрового Мастера.
- `admin.html` — системное управление администратора.
- `source.html` — просмотр исходных материалов правил.
- `tz-structured.html` — структурированный каталог ТЗ.

## Архитектура игры

В новой структуре конкретная партия является центром игрового процесса:

`Игра → Игрок → Владыка → Осколки → Ход → Мастер → результат`

Страницы отдельных Владык больше не создаются вручную. Данные загружаются из базы через `lord.html?id=...`.

## Исходные правила

Авторитетный исходник правил находится в каталоге `source/`. Там хранятся исходный PDF, структурированная рабочая редакция и документация по структуре источника.

`rules-source-data.js` является генерируемым файлом и не должен редактироваться вручную. Его собирает GitHub Actions workflow `Build VA-34 source data`.

## База данных

SQL-файлы в корне репозитория являются схемами и миграциями Supabase. Они сохраняются отдельно от клиентского кода, поскольку используются при развёртывании и изменении структуры базы.

## Публикация на GitHub Pages

1. Откройте Settings → Pages.
2. Выберите ветку `main` и корень репозитория.
3. Сайт будет доступен по адресу GitHub Pages проекта.

## Администратор и Мастер

Роли разделены:

- **Администратор** — системный статус. Не получает права Мастера и не может работать в кабинете Мастера.
- **Мастер** — отдельный статус, дающий права игрового Мастера.
- Администратор может назначать и снимать статус Мастера через `admin.html`.
- Администратор не может одновременно иметь статус Мастера.

Для существующего Supabase-проекта один раз выполните `admin-schema.sql` в SQL Editor. Первый Администратор назначается вручную в Supabase:

```sql
update public.players
set is_admin = true
where id = 'UUID_ПОЛЬЗОВАТЕЛЯ';
```

После этого администратор входит в `admin.html` и назначает Мастеров. Изменять флаги ролей через обычный профиль пользователя запрещено.
