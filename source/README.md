# VA-34 source

Положите сюда авторитетный PDF `компиляция ВА34.pdf`.

После этого запустите GitHub Actions workflow **Build VA-34 source data** вручную либо измените/добавьте PDF через commit. Workflow извлечёт полный текст PDF, проверит ключевые разделы (включая «Вдохновение Астрала. Расы») и пересоберёт `rules-source-data.js`.

`rules-source-data.js` является генерируемым файлом и не должен редактироваться вручную.
