# 🌌 Вдохновение Астрала

Стратегия по мотивам вселенной Эадора — полные правила.

## 📁 Структура проекта

```
├── index.html      — главная страница с правилами
├── styles.css      — стили страницы
└── README.md       — этот файл
```

## 🚀 Как использовать

1. Скачайте все файлы в одну папку.
2. Откройте `index.html` в любом браузере — всё работает без сборки и зависимостей.
3. Для публикации на GitHub: создайте новый репозиторий, загрузите оба файла (`index.html` и `styles.css`) в корень.
4. Включите GitHub Pages (Settings → Pages → Source: main branch), и сайт будет доступен по ссылке вида `https://<username>.github.io/<repo>/`.

## 👑 Страницы Владык

В разделе «Страницы Владык» находится сетка из 15 карточек. Вставьте ссылки на страницы Владык в атрибут `href` тега `<a>`:

```html
<div class="lord-card">
  <h3>Владыка 1</h3>
  <p><a href="https://example.com/vladyka1">Имя Владыки</a></p>
</div>
```

## 📋 Ход ИС

В разделе «Ход ИС» — 20 карточек для ссылок на игровые состояния. Аналогично вставьте ссылки:

```html
<div class="is-card">
  <h3>Ход 1</h3>
  <p><a href="https://example.com/is-1">ИС Хода 1</a></p>
</div>
```

## 🎨 Оформление

Страница использует тёплую палитру, серифный шрифт и адаптивную вёрстку. Слева — навигация со всеми разделами (липкая, с прокруткой). Каждый раздел выделен цветной полосой сверху.
