# Вдохновение Астрала

Стратегия по мотивам вселенной Эадора — правила и страницы владык.

## Файлы

- `index.html` — главная страница с правилами
- `styles.css` — единый CSS (без медиа-запросов, один стиль для всех устройств)
- `taminar.html` — страница владыки Таминара

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы в корень репозитория
3. Settings → Pages → Source: main branch, папка: root
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`

## Добавление страницы владыки

1. Скопируйте `taminar.html` → `imya.html`
2. Замените содержимое на данные нового владыки
3. В `index.html` в разделе «Страницы Владык» впишите ссылку:
   ```html
   <a href="imya.html">Имя Владыки</a>
   ```

## Добавление хода ИС

В `index.html` в разделе «Ход ИС» впишите ссылку:
```html
<div class="turn-card"><h4>Ход 1</h4><p><a href="hod1.html">Ход 1 — ИС</a></p></div>
```


## Администратор и Мастер

Роли разделены:

- **Администратор** — системный статус. Не получает права Мастера и не может работать в кабинете Мастера.
- **Мастер** — отдельный статус, дающий права игрового Мастера.
- Администратор может назначать и снимать статус Мастера через `admin.html`.
- Администратор не может одновременно иметь статус Мастера.

Для существующего Supabase-проекта один раз выполните `admin-schema.sql` в SQL Editor. Первый Администратор назначается вручную в Supabase:

```sql
update public.players
set is_admin = true
where id = 'UUID_ПОЛЬЗОВАТЕЛЯ';
```

После этого администратор входит в `admin.html` и назначает Мастеров. Изменять флаги ролей через обычный профиль пользователя запрещено.
