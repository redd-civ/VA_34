# VA-34 source

## Авторитетный исходник

Основной исходный PDF: **компиляция ВА34.pdf**.

Он сохраняется без изменений и используется workflow **Build VA-34 source data** для генерации `rules-source-data.js`.

## Структурированная редакция

**ВА34_структурированная_полная_редакция.pdf** — отдельная рабочая редакция исходника.

Она не заменяет авторитетный PDF. В ней материал разложен по разделам:

- общие правила;
- расы;
- войска, ресурсы, ландшафт и герои;
- описания школ магии;
- описания технологий;
- общий раздел ТЗ;
- каталог уровней ТЗ;
- дополнительные цифры и поздние обновления;
- журнал обнаруженных конфликтов числовых правил.

В структурированной редакции исходные формулировки правил не «исправляются» автоматически. Если в исходнике встречаются разные значения одного правила, они сохраняются, а конфликт выносится отдельно для решения автора.

## Генерация source data

После изменения авторитетного PDF запустите GitHub Actions workflow **Build VA-34 source data** вручную либо измените/добавьте PDF через commit. Workflow извлечёт полный текст PDF, проверит ключевые разделы (включая «Вдохновение Астрала. Расы») и пересоберёт `rules-source-data.js`.

`rules-source-data.js` является генерируемым файлом и не должен редактироваться вручную.
